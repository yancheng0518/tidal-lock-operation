# 潮闸行动 · Tidal Lock

[开始网页版试玩](https://yancheng0518.github.io/tidal-lock-operation/)

单人第一人称 WebGL 2 游戏。进入潮闸港区，清除六名守卫即可完成任务。当前版本为 1.2.0。

WASD 移动，Shift 冲刺，鼠标环视，左键射击，按住右键瞄准。Q / E 向左或向右探头，空格跳跃，C 或 Ctrl 下蹲，R 换弹，P 或 Esc 暂停。
