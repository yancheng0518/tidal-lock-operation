# 潮闸行动 · Tidal Lock

[开始网页版试玩](https://yancheng0518.github.io/tidal-lock-operation/)

单人第一人称游戏。进入潮闸港区，清除六名守卫即可完成任务。当前版本为 1.2.2。

WASD 移动，Shift 冲刺，鼠标环视，左键射击，按住右键瞄准。Q / E 向左或向右探头，空格跳跃，C 或 Ctrl 下蹲，R 换弹，P 或 Esc 暂停。

手机点「开始行动」后横屏游玩。左手推住摇杆，右手点「左探」或「右探」。点另一侧直接换边，再点当前侧回正。在探头键或射击键上拖动也能转动视角。

普通入口会尝试三维画面，遇到图形设备或场景加载故障时自动切入轻量画面。在部署页点「兼容模式」也可以直接进入同一关卡，跳过 WebGL 初始化和三维模型下载。[手机兼容版入口](https://yancheng0518.github.io/tidal-lock-operation/?mode=compat&v=1.2.2)
